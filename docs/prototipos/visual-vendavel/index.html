Como montar uma página nova

A casca (menu, topo do celular, barra inferior, "Pular para o conteúdo") e a barra da prévia vêm do base.js.

<!doctype html>
<html lang="pt-BR">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Nome da tela · Prévia visual vendável</title>
<!-- Dados fictícios (D8). Nada aqui fala com a API. -->
<link rel="stylesheet" href="base.css">
<script src="base.js"></script>   <!-- sem defer: pinta a marca antes do primeiro quadro -->
</head>
<body data-casca="treinador" data-ativo="planejamento">   <!-- ou data-casca="aluno" data-ativo="treino" -->
<main id="conteudo" class="pagina">          <!-- .pagina--editor limita a 1040 -->
  <header class="cab-pagina"> … um único h1.t-titulo-pagina … </header>
  …
</main>
</body>
</html>

Ids de data-ativo: treinador inicio alunos atualizacoes agenda comunidade biblioteca planejamento interessados financeiro numeros perfil equipe ajuda; aluno inicio treino dieta time historico conta. Ícones: <svg class="ic" aria-hidden="true"><use href="#i-haltere"/></svg> ou VV.icone('haltere'). Composição: data-composicao="aq:1 fs:3 ws:1 top:1 bo:2". HTML montado depois do carregamento chama VV.desenharComposicoes(raiz). Mudança de marca ou paleta dispara o evento vv:tema no document.
